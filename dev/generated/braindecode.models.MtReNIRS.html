braindecode.models.MtReNIRS#

class braindecode.models.MtReNIRS(n_outputs=None, n_chans=None, chs_info=None, n_times=None, input_window_seconds=None, sfreq=None, *, window_samples=100, embed_dim=128, depth=6, num_heads=4, mlp_dim=512, n_fourier_bands=6, spatial_hidden_dim=128, rope_base=500.0, qk_norm=True, pool='temporal_mean', on_non_divisible='crop', coordinate_center=(0.00021245056996122003, -0.022675372660160065, 0.020025914534926414), coordinate_scale=0.09265176206827164, drop_prob=0.1, activation=<class 'torch.nn.modules.activation.GELU'>)[source]#

MtReNIRS from Chae et al. (2026).

Attention/Transformer Channel Foundation Model

Added in version 2.1.

MtReNIRS (Montage-aligned transferable Representations for fNIRS) is a montage-aware masked autoencoder pretrained on 12 public fNIRS datasets (268 subjects, 567 recording hours) [1]. A token is one 10-s window of one chromophore channel, tagged with the canonical 10-05 position [2] of its source-detector (S-D) pair and with its chromophore, so any montage is a set of tokens that Transformer blocks mix, with the window index as their only time code.

Architecture Overview

With W = n_times // window_samples windows, C = n_chans HbO/HbR rows and D = embed_dim:

  1. Windowing: (batch, C, n_times) is cut into non-overlapping 10-s windows \(x_{c,t}\), (batch, W, C, window_samples); a short last window is cropped (on_non_divisible).

  2. Token embedding: each window becomes a token \(z_{c,t}\), the sum of its signal embedding and of the spatio-chromophore embedding of its channel, (batch, W * C, D).

  3. Transformer encoder: depth pre-norm blocks attend over all channels and windows jointly, then a final LayerNorm; invalid tokens are never attended and are zeroed, (batch, W, C, D).

  4. Readout and head: pool reduces the tokens to (batch, feature_dim) and final_layer gives (batch, n_outputs).

Macro Components

  • Token embedding (embed, _TokenEmbedding).

    • Operations. embed.signal_proj, nn.Linear(100, 128), projects each window \(x_{c,t}\). embed.spatial_mlp, nn.Linear(48, 128), GELU, nn.Linear(128, 128), embeds the Fourier features [3] of \(u_c = [q_c^\top, b_c]^\top\), the canonical coordinate \(q_c\) of the S-D pair and the chromophore \(b_c\) (0 HbO, 1 HbR):

      \[\phi(u_c) = \left[\sin(2^k \pi u_{c,j}),\, \cos(2^k \pi u_{c,j}) \right]_{j = 1, \dots, 4}^{k = 0, \dots, 5} \in \mathbb{R}^{48}, \qquad z_{c,t} = W_x x_{c,t} + b_x + \mathrm{MLP}(\phi(u_c)).\]

    • Role. Region-specific activity and the coupled, often opposing HbO/HbR dynamics are told apart, with no class token and no per-channel table.

  • Canonical coordinates (default_coordinates, or the coordinates argument of forward()).

    • Operations. \(\hat{q}_c = (q_c - \mu) / \sigma\), with \(\mu\) = coordinate_center and \(\sigma\) = coordinate_scale taken from the pretraining corpus.

    • Role. The paper aligns each montage to the 10-05 system and assigns every channel the coordinate of its slot. That alignment and slot assignment (the authors’ mtrenirs.alignment.align, Sec. III-B, Eq. 1) stay outside this class, which reads \(q_c\) from loc[:3] of chs_info.

  • Transformer encoder (encoder.blocks, encoder.norm; _TransformerBlock, _RotarySelfAttention).

    • Operations. Six pre-norm blocks of a 128-dimensional state, four heads, a 512-dimensional MLP and 0.1 dropout. With \(y\) the normalized input, a block computes

      \[h = z + \mathrm{Drop}\big(\mathrm{Attn}(\mathrm{LN}_1(z))\big), \qquad z' = h + \mathrm{MLP}(\mathrm{LN}_2(h)),\]
      \[\mathrm{Attn}_n = \sum_m \mathrm{softmax}_m\!\left( \frac{(\mathcal{R}_{t_n} \mathrm{LN}_q(W_q y_n))^\top \mathcal{R}_{t_m} \mathrm{LN}_k(W_k y_m)}{\sqrt{d_h}} + M_m \right) W_v y_m,\]

      where \(\mathcal{R}_t\) is the rotary rotation [4] of the window index \(t\) with frequencies \(\beta^{-2j/d_h}\), \(\beta\) = rope_base, and \(M_m = 0\) for a valid key and \(-\infty\) otherwise. In each head the queries and keys are layer-normalized and rotated, so a logit depends on the difference of two window indices.

    • Role. The window order is kept without mixing time with spatial identity: all S-D pairs of a window share its index, and the spatial identity enters only through the coordinate embedding.

  • Readout and head (pool, final_layer).

    • Operations. "temporal_mean" (default): mean over the valid windows, one embed_dim vector per channel, concatenated; "channel_temporal_mean": mean over the valid windows and channels; "flatten": all tokens. Then nn.Linear.

    • Role. The linear probe of the paper on frozen features (Sec. III-D): the temporal average keeps the feature size fixed.

Temporal, Spatial, and Spectral Encoding

  • Temporal. Within a window, the 100 input weights of the signal projection (no convolution); across windows, the rotary encoding of the window index only. The weights expect 10 Hz and 10-s windows.

  • Spatial. Every row of x is one chromophore channel, in any order and number; the HbO and HbR rows of one S-D pair share \(q_c\).

  • Spectral. None in the model. The weights expect HbO/HbR band-passed to 0.01-0.5 Hz and z-scored per channel.

  • Chromophores. Read from MNE’s coil_type or the " hbo" / " hbr" name suffix; any other channel (e.g. HbT) raises.

Additional Mechanisms

  • Missing data. A window with a NaN sample, a channel without a location (NaN or all-zero loc) and a padded channel (ch_mask) are left out of the attention and of the pooling.

  • Scope. The masked-autoencoder decoder and the 25 % token masking of pretraining (Fig. 2D, Sec. III-C) are not part of this class. final_layer and pool="channel_temporal_mean" are additions (the reference returns features only); the reference’s remainder="overlap" is not offered.

Pretrained Weights

mtrenirs_10s.pt of microsoft/MtReNIRS (commit 16c3082, MIT), the paper’s epoch-95 checkpoint of the 10-s model, holds the inference encoder only. It is on the Hugging Face Hub at braindecode/mtrenirs-pretrained; the head is not pretrained. It expects 10 Hz HbO/HbR in 100-sample windows, with positions on 10-05 slots, preprocessed as in Sec. III-B (Fig. 2A): optical density, temporal derivative distribution repair and the modified Beer-Lambert law; a 0.01-0.5 Hz band-pass, resampling to 10 Hz and removal of flat or low-variance chromophore channels; each chromophore channel z-scored over its run and clipped to \([-6, 6]\); downstream windows [onset, onset + 10 s) without a hemodynamic-response shift. For the band-pass, the authors’ released from_mne_raw uses MNE’s default FIR, which leaves 43.8 % of the window power above 0.5 Hz; a zero-phase third-order Butterworth, raw.filter(0.01, 0.5, method="iir", iir_params=dict(order=3, ftype="butter")), leaves 1.1 % and reproduces the paper’s numbers (#1564). On the released checkpoint, the "foundation" tokens of encode() equal the output of the authors’ MtReNIRSEncoder (MtReNIRS@16c3082) with max-abs difference 0.0:

# raw: MNE Raw with the 10-05 slot positions in loc[:3]
model = MtReNIRS.from_pretrained(
    "braindecode/mtrenirs-pretrained",
    chs_info=raw.info["chs"],
    n_outputs=3,
    n_times=100,
)

License

Parameters:

  • n_outputs (int | None) – Number of outputs of the model. This is the number of classes in the case of classification.

  • n_chans (int | None) – Number of EEG channels.

  • chs_info (list[dict] | None) – Information about each individual EEG channel. This should be filled with info["chs"]. Refer to mne.Info for more details.

  • n_times (int | None) – Number of time samples of the input window.

  • input_window_seconds (float | None) – Length of the input window in seconds.

  • sfreq (float | None) – Sampling frequency of the EEG recordings.

  • window_samples (int) – Samples per token window \(x_{c,t}\): 10 s at 10 Hz.

  • embed_dim (int) – Token and Transformer width.

  • depth (int) – Number of Transformer blocks.

  • num_heads (int) – Attention heads; embed_dim // num_heads must be even for RoPE.

  • mlp_dim (int) – Hidden width of each block’s feed-forward network.

  • n_fourier_bands (int) – Fourier bands \(2^k \pi\) per coordinate of \(u_c\); six give 48 features.

  • spatial_hidden_dim (int) – Hidden width of the spatio-chromophore MLP (48 -> 128 -> 128 by default).

  • rope_base (float) – Rotary base \(\beta\) of the window index.

  • qk_norm (bool) – Per-head LayerNorm of queries and keys.

  • pool (Literal['temporal_mean', 'channel_temporal_mean', 'flatten']) – Readout of the (batch, n_windows, n_chans, embed_dim) tokens (see Macro Components); "channel_temporal_mean" takes ch_mask.

  • on_non_divisible (Literal['crop', 'pad', 'error']) – A short last window is dropped (the reference’s remainder="drop"), zero-padded or refused.

  • coordinate_center (tuple[float, float, float]) – Centre \(\mu\) (m) subtracted from \(q_c\); the checkpoint’s data.pos_center.

  • coordinate_scale (float) – RMS scale \(\sigma\) (m) dividing the centred \(q_c\); the checkpoint’s data.pos_scale.

  • drop_prob (float) – Dropout of attention weights, attention output and MLP.

  • activation (type[Module]) – Activation of the spatio-chromophore MLP and the feed-forward blocks.

Raises:

ValueError – If some input signal-related parameters are not specified: and can not be inferred.

Notes

If some input signal-related parameters are not specified, there will be an attempt to infer them from the other parameters.

Hugging Face Hub integration

When the optional huggingface_hub package is installed, all models automatically gain the ability to be pushed to and loaded from the Hugging Face Hub. Install with:

pip install braindecode[hub]

Pushing a model to the Hub:

from braindecode.models import MtReNIRS

# Train your model
model = MtReNIRS(n_chans=22, n_outputs=4, n_times=1000)
# ... training code ...

# Push to the Hub; ``datasets`` and ``base_model`` go to the card
model.push_to_hub(
    repo_id="username/my-mtrenirs-model",
    commit_message="Initial model upload",
    model_card_kwargs={"datasets": ["BNCI2014_001"]},
)

Loading a model from the Hub:

from braindecode.models import MtReNIRS

# Load pretrained model
model = MtReNIRS.from_pretrained("username/my-mtrenirs-model")
# Data the weights were trained on, from the Hub model card
print(model.card_data.datasets if model.card_data else None)

# Load with a different number of outputs (head is rebuilt automatically)
model = MtReNIRS.from_pretrained("username/my-mtrenirs-model", n_outputs=4)

Extracting features and replacing the head:

import torch

x = torch.randn(1, model.n_chans, model.n_times)
# Extract encoder features (consistent dict across all models)
out = model(x, return_features=True)
features = out["features"]

# Replace the classification head
model.reset_head(n_outputs=10)

Saving and restoring full configuration:

import json

config = model.get_config()            # all __init__ params
with open("config.json", "w") as f:
    json.dump(config, f)

model2 = MtReNIRS.from_config(config)    # reconstruct (no weights)

All model parameters (both EEG-specific and model-specific such as dropout rates, activation functions, number of filters) are automatically saved to the Hub and restored when loading.

See Loading and Adapting Pretrained Foundation Models for a complete tutorial.

encode(x, coordinates=None, ch_mask=None)[source]#

Tokenize the recording and encode its (channel, window) tokens.

Parameters:

  • x (Tensor) – Hemoglobin concentrations, (batch, n_chans, n_times). A NaN sample masks its window.

  • coordinates (Optional[Tensor]) – \(u_c\) of the channels of x, (n_chans, 4) or (batch, n_chans, 4): standardized position and chromophore (0 HbO, 1 HbR). NaN positions mark channels without a location. None uses the coordinates built from chs_info.

  • ch_mask (Optional[Tensor]) – True for real channels, (batch, n_chans).

Returns:

"foundation", the encoded tokens, (batch, n_windows, n_chans, embed_dim), zero where a token is not valid, and "valid", the validity of each token, (batch, n_windows, n_chans).

Return type:

dict[str, Tensor]

Forward pass.

Parameters:

  • x (Tensor) – Hemoglobin concentrations, (batch, n_chans, n_times).

  • return_features (bool) – Return the pooled features instead of the logits.

  • coordinates (Optional[Tensor]) – \(u_c\) of the channels of x, as in encode().

  • ch_mask (Optional[Tensor]) – True for real channels, (batch, n_chans) (check_ch_mask()). Needs pool="channel_temporal_mean"; padded channels are left out of the attention and the pooling.

Returns:

Logits (batch, n_outputs), or with return_features a dict with features (batch, feature_dim) and cls_token (None: the model has no class token).
