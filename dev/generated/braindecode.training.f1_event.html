braindecode.training.f1_event#

braindecode.training.f1_event(pred_events, gt_events, iou_threshold=0.5)[source]#

COCO-style greedy event F1: TP requires IoU > threshold AND class match.

Inputs are lists of (start, end, class[, conf]) tuples with class in 1..n_classes-1 (CLASS-0 CONTRACT: callers never pass class 0 – decoded detections skip argmax == 0 and the target builder never stores class 0).

Return type:

float
