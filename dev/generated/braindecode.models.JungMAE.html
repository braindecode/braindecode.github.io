braindecode.models.JungMAE#

class braindecode.models.JungMAE(n_outputs=None, n_chans=None, chs_info=None, n_times=None, input_window_seconds=None, sfreq=None, *, patch_size=10, embed_dim=192, depth=4, num_heads=8, mlp_ratio=4.0, drop_prob=0.1, head_drop_prob=0.1, minimum_patch_valid_fraction=0.8, activation=<class 'torch.nn.modules.activation.GELU'>, channel_order=None, on_non_divisible='error')[source]#

JungMAE from Jung et al. (2025), as implemented by the GeoNIRS authors.

Attention/Transformer Foundation Model

Added in version 2.1.

Jung, Lee and An [1] pretrain a masked autoencoder on unlabelled fNIRS recordings, so that a decoder needs fewer labelled ones. Their paper (IEEE BCI 2025) came without code: this class is the encoder of the GeoNIRS authors’ implementation, whose Jung-MAE baseline it is ([2], GeoNIRS/GeoNIRS at commit 81f8995), with a linear head; the pretraining decoder is not part of it.

Architecture Overview

Every HbO/HbR pair (one source-detector channel) is a sequence of its own: its window is cut into 2 s patches, each patch becomes one token holding both chromophores, and a Transformer encodes the tokens of each pair. The same weights serve every pair, which is how one checkpoint handles montages of any size; the classifier then flattens the tokens of all the pairs. With \(B\) the batch size, \(C\) = n_chans // 2 pairs, \(Q\) = patch_size, \(P\) patches and \(D\) = embed_dim:

x (B, 2C, n_times): HbO and HbR rows, NaN = missing sample
1. HbO/HbR split, invalid samples to zero  -> (B, C, P*Q) each
2. to_patches: [HbO_t, HbR_t, ...]         -> (B*C, P, 2Q)
3. patch_embed + sinusoidal position       -> (B*C, P, D)
4. encoder, invalid patches not attended   -> (B, C, P, D)   encode()
5. flatten_layer, head_dropout             -> (B, C*P*D)
6. final_layer                             -> (B, n_outputs)

Macro Components

  • JungMAE.patch_embed Patch tokenization

    Operations. A patch interleaves the \(Q\) HbO samples \(o\) and HbR samples \(r\) of pair \(c\). One Linear maps it to a \(D\)-wide token, and the fixed sinusoidal encoding of the patch index \(p\) is added:

    \[\mathbf{z}_{c,p} = \mathbf{W}\,[o_{c,pQ},\, r_{c,pQ},\, \dots,\, o_{c,pQ+Q-1},\, r_{c,pQ+Q-1}] + \mathbf{b} + \mathrm{PE}(p).\]

    Role. One token per patch, with both chromophores of each time step.

  • JungMAE.encoder Transformer encoder

    Operations. Four pre-norm TransformerEncoderLayer blocks (8 heads, feed-forward width 768, GELU) and a final LayerNorm, over the \(P\) tokens of one pair. Invalid patches are masked as attention keys; the reference packs the valid tokens instead, which gives the same features up to float32 rounding.

    Role. Context across the time of a pair, with the same weights for every pair.

  • JungMAE.final_layer Classification head

    Flatten, Dropout and one Linear, the flatten_linear head of the GeoNIRS benchmark. The benchmark standardizes the flattened features with training-set statistics first; this head does not, so standardize the eval-mode return_features to reproduce it. The head is not pretrained, and its input size fixes n_chans and n_times.

Temporal, Spatial, and Spectral Encoding

  • Temporal. Non-overlapping 2 s patches (10 samples at 5 Hz) with a fixed sinusoidal position. The weights were pretrained on 30 s windows.

  • Spatial. None. Pairs never attend to each other and the model sees no optode position. A pair is identified only by where its features sit in the head input, so the pairs must keep the order used in training.

  • Spectral. None: there is no frequency decomposition.

  • Chromophores. HbO and HbR share each token, sample by sample; HbT is not used. The rows must be the HbO and the HbR rows of the same pairs (see channel_order).

Additional Mechanisms

  • Missing data. NaN marks a missing sample, and a pair whose rows are all NaN is a missing channel: the head spans every pair, so there is no ch_mask. A sample is valid when both chromophores are finite, and a patch when at least minimum_patch_valid_fraction of its samples are (\(\lceil 0.8\,Q \rceil\) by default). Invalid samples are set to zero, invalid patches are not attended and give zero tokens, and a pair without a valid patch gives zero features.

Pretrained Weights

The encoder of jung_mae.pt, trained by the GeoNIRS authors and converted to these parameter names, is on the Hugging Face Hub at braindecode/jungmae-pretrained; the head is not pretrained. The weights expect the inputs of the GeoNIRS paper (Appendix B.1): HbO and HbR in µmol/L resampled to 5 Hz, each chromophore z-scored per recording over all its valid channels and time points. With them and the GeoNIRS benchmark’s linear-probe loop, this class reproduces the paper’s Jung-MAE-LP results (#1589).

from braindecode.models import JungMAE

model = JungMAE.from_pretrained(
    "braindecode/jungmae-pretrained", n_chans=40, n_outputs=2, n_times=60
)
Parameters:

  • n_outputs (int | None) – Number of outputs of the model. This is the number of classes in the case of classification.

  • n_chans (int | None) – Number of EEG channels.

  • chs_info (list[dict] | None) – Information about each individual EEG channel. This should be filled with info["chs"]. Refer to mne.Info for more details.

  • n_times (int | None) – Number of time samples of the input window.

  • input_window_seconds (float | None) – Length of the input window in seconds.

  • sfreq (float | None) – Sampling frequency of the EEG recordings.

  • patch_size (int) – Samples per patch (patch_samples in the reference), 2 s at 5 Hz.

  • embed_dim (int) – Width of the tokens (encoder_dim in the reference).

  • depth (int) – Number of Transformer layers (encoder_layers in the reference).

  • num_heads (int) – Attention heads per layer (encoder_heads in the reference).

  • mlp_ratio (float) – Feed-forward width over embed_dim.

  • drop_prob (float) – Dropout of the encoder layers (dropout in the reference).

  • head_drop_prob (float) – Dropout before final_layer (head_dropout in the benchmark).

  • minimum_patch_valid_fraction (float) – Fraction of valid samples a patch needs, in (0, 1].

  • activation (type[Module]) – Activation of the feed-forward layers.

  • channel_order (Optional[Literal['stacked', 'interleaved']]) – [HbO_1..HbO_C, HbR_1..HbR_C] or MNE’s [HbO_1, HbR_1, ...]; None reads it from chs_info ("stacked" without it). n_chans must be even.

  • on_non_divisible (Literal['error', 'pad', 'crop']) – n_times not a multiple of patch_size: raise, as the reference does; pad with missing samples, to which the validity rule applies; or crop.

Raises:

ValueError – If some input signal-related parameters are not specified: and can not be inferred.

Notes

If some input signal-related parameters are not specified, there will be an attempt to infer them from the other parameters.

Hugging Face Hub integration

When the optional huggingface_hub package is installed, all models automatically gain the ability to be pushed to and loaded from the Hugging Face Hub. Install with:

pip install braindecode[hub]

Pushing a model to the Hub:

from braindecode.models import JungMAE

# Train your model
model = JungMAE(n_chans=22, n_outputs=4, n_times=1000)
# ... training code ...

# Push to the Hub; ``datasets`` and ``base_model`` go to the card
model.push_to_hub(
    repo_id="username/my-jungmae-model",
    commit_message="Initial model upload",
    model_card_kwargs={"datasets": ["BNCI2014_001"]},
)

Loading a model from the Hub:

from braindecode.models import JungMAE

# Load pretrained model
model = JungMAE.from_pretrained("username/my-jungmae-model")
# Data the weights were trained on, from the Hub model card
print(model.card_data.datasets if model.card_data else None)

# Load with a different number of outputs (head is rebuilt automatically)
model = JungMAE.from_pretrained("username/my-jungmae-model", n_outputs=4)

Extracting features and replacing the head:

import torch

x = torch.randn(1, model.n_chans, model.n_times)
# Extract encoder features and a mean-pooled 2-D embedding
out = model(x, return_features=True)
embedding = out["embedding"]  # (batch, dim)
features = out["features"]

# Replace the classification head
model.reset_head(n_outputs=10)

Note that torch.jit.script returns features only on models whose forward declares return_features.

Saving and restoring full configuration:

import json

config = model.get_config()            # all __init__ params
with open("config.json", "w") as f:
    json.dump(config, f)

model2 = JungMAE.from_config(config)    # reconstruct (no weights)

All model parameters (both EEG-specific and model-specific such as dropout rates, activation functions, number of filters) are automatically saved to the Hub and restored when loading.

See Loading and Adapting Pretrained Foundation Models for a complete tutorial.

Methods

encode(x)[source]#

Encode the patches of every HbO/HbR pair.

The window is cut into whole patches. A sample is valid when both chromophores are finite, and a patch when enough of its samples are. Each patch of a pair, its invalid samples set to zero, becomes a token with its sinusoidal position; the Transformer encodes the tokens of each pair with the invalid patches hidden as keys, and the invalid tokens are zeroed.

Parameters:

x (Tensor) – Input tensor with shape (batch_size, n_chans, n_times). NaN marks a missing sample.

Returns:

"foundation", the tokens with shape (batch_size, n_pairs, n_patches, embed_dim), zero at the invalid patches, and "valid", the boolean patch validity with shape (batch_size, n_pairs, n_patches). These are the names of the reference.

Return type:

dict[str, Tensor]

forward(x, return_features=False, ch_mask=None)[source]#

Forward pass of the JungMAE model.

Parameters:

  • x (Tensor) – Input tensor with shape (batch_size, n_chans, n_times). NaN marks a missing sample.

  • return_features (bool) – If True, return the input of final_layer instead of the logits.

  • ch_mask (Tensor | None) – Pass by keyword. (batch_size, n_chans) mask with True for real channels, see check_ch_mask(). Padded channels are read as missing samples (NaN).

Returns:

Output tensor with shape (batch_size, n_outputs), or {"features": (batch_size, n_pairs * n_patches * embed_dim), "cls_token": None} with return_features=True.

Return type:

Tensor | dict[str, Tensor | None]

reset_head(n_outputs)[source]#

Replace the classification head for a new number of outputs.

This is called automatically by from_pretrained() when the user passes an n_outputs that differs from the saved config, and attaches a head to a model built with n_outputs=None. The default replaces the last linear or convolutional layer of final_layer by a new one with n_outputs outputs, and raises NotImplementedError when that layer is constrained, when final_layer holds more than one such layer, or when it does not end with one. Override in subclasses that need a model-specific head structure. Implementations keep changed constructor arguments in sync with self._update_init_kwargs, so that a saved model can be loaded back. Implementations requiring positive outputs can also use self._set_n_outputs to validate and record the new value.

Parameters:

n_outputs (int) – New number of output classes.

Return type:

None
