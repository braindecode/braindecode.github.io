braindecode.models.NICE#

class braindecode.models.NICE(n_outputs=None, n_chans=None, chs_info=None, n_times=None, input_window_seconds=None, sfreq=None, *, n_filters=40, filter_time_length=25, pool_time_length=51, pool_time_stride=5, embed_dim=768, activation=<class 'torch.nn.modules.activation.ELU'>, drop_prob=0.5, drop_prob_proj=0.5)[source]#

NICE EEG/MEG encoder from Song et al. (2024) [song2024nice].

Convolution

Added in version 2.1.

Architecture Overview

NICE (Natural Image Contrast EEG) learns an EEG/MEG embedding aligned with the image embedding of a frozen CLIP ViT-L/14 by contrastive learning, and decodes seen images zero-shot by nearest-neighbour search in that space. This class is the brain branch, the TSConv encoder (Enc_eeg) and its projector (Proj_eeg), plus a linear head:

(batch, n_chans, n_times) -> TSConv -> 1x1 convolution -> flatten ->
projector -> (batch, embed_dim) -> (batch, n_outputs)

Macro Components

NICE.tsconv and NICE.projection

Operations. A temporal convolution with n_filters kernels of size (1, filter_time_length), average pooling of size (1, pool_time_length) and stride (1, pool_time_stride), batch norm + activation, a spatial convolution over all n_chans, batch norm + activation, dropout and a 1x1 convolution. Unlike EEGConformer’s patch embedding, the pooling comes before the spatial convolution. Role. Temporal and spatial features, (batch, n_filters, 1, n_steps).

NICE.projector

Operations. The flattened (time, filters) map goes through a linear layer to embed_dim, then LayerNorm(x + Dropout(Linear(GELU(x)))). Role. Its output is the aligned embedding, returned as "features" by return_features=True; the contrastive loss L2-normalises it.

NICE.final_layer

Operations. Linear classifier on the embedding. Role. Not in the original, which only does retrieval.

Temporal, Spatial, and Spectral Encoding

  • Temporal: the convolution and the pooling give n_steps tokens, each reading filter_time_length + pool_time_length - 1 samples (75 with defaults).

  • Spatial: one convolution over all n_chans mixes the montage, which is fixed at construction.

  • Spectral: no explicit transform; the n_filters temporal kernels learn the bands.

Additional Mechanisms

  • The paper uses THINGS-EEG2 (63 channels, 250 Hz, 0-1 s, so n_chans=63, n_times=250) and, in its appendix A.6, THINGS-MEG (271 channels, 200 Hz, 0-1 s, so n_chans=271, n_times=200), with the same TSConv hyperparameters. The plug-in spatial modules of the paper (NICE-SA, NICE-GA) are not included.

  • mask hides raw samples before the temporal convolution, and return_features adds the temporal "tokens" (see forward()).

  • No pretrained weights: the authors’ checkpoint (eeyhsong/NICE, CC-BY-NC-ND-4.0, 10 subjects of THINGS-EEG2) is not supported; at its revision 7f98b08 the encoder file is truncated.

Parameters:

  • n_outputs (int) – Number of outputs of the model. This is the number of classes in the case of classification.

  • n_chans (int) – Number of EEG channels.

  • chs_info (list of dict) – Information about each individual EEG channel. This should be filled with info["chs"]. Refer to mne.Info for more details.

  • n_times (int) – Number of time samples of the input window.

  • input_window_seconds (float) – Length of the input window in seconds.

  • sfreq (float) – Sampling frequency of the EEG recordings.

  • n_filters (int) – Number of temporal and spatial filters (k in the paper).

  • filter_time_length (int) – Temporal kernel length (m1).

  • pool_time_length (int) – Average-pooling length (m2).

  • pool_time_stride (int) – Average-pooling stride (s).

  • embed_dim (int) – Size of the aligned embedding, the CLIP ViT-L/14 image feature size.

  • activation (type[Module]) – Activation of the convolutional encoder.

  • drop_prob (float) – Dropout of the convolutional encoder.

  • drop_prob_proj (float) – Dropout in the projector’s residual branch.

Raises:

Hugging Face Hub integration

When the optional huggingface_hub package is installed, all models automatically gain the ability to be pushed to and loaded from the Hugging Face Hub. Install with:

pip install braindecode[hub]

Pushing a model to the Hub:

from braindecode.models import NICE

# Train your model
model = NICE(n_chans=22, n_outputs=4, n_times=1000)
# ... training code ...

# Push to the Hub; ``datasets`` and ``base_model`` go to the card
model.push_to_hub(
    repo_id="username/my-nice-model",
    commit_message="Initial model upload",
    model_card_kwargs={"datasets": ["BNCI2014_001"]},
)

Loading a model from the Hub:

from braindecode.models import NICE

# Load pretrained model
model = NICE.from_pretrained("username/my-nice-model")
# Data the weights were trained on, from the Hub model card
print(model.card_data.datasets if model.card_data else None)

# Load with a different number of outputs (head is rebuilt automatically)
model = NICE.from_pretrained("username/my-nice-model", n_outputs=4)

Extracting features and replacing the head:

import torch

x = torch.randn(1, model.n_chans, model.n_times)
# Extract encoder features (consistent dict across all models)
out = model(x, return_features=True)
features = out["features"]

# Replace the classification head
model.reset_head(n_outputs=10)

Saving and restoring full configuration:

import json

config = model.get_config()            # all __init__ params
with open("config.json", "w") as f:
    json.dump(config, f)

model2 = NICE.from_config(config)    # reconstruct (no weights)

All model parameters (both EEG-specific and model-specific such as dropout rates, activation functions, number of filters) are automatically saved to the Hub and restored when loading.

See Loading and Adapting Pretrained Foundation Models for a complete tutorial.

Methods

forward(x, return_features=False, mask=None)[source]#

Encode x of shape (batch, n_chans, n_times).

Returns logits (batch, n_outputs). return_features=True returns "features" (the aligned embedding, (batch, embed_dim)), "cls_token" (None), and "tokens" (batch, n_steps, n_filters): the projected temporal convolution map before flattening and the global projector, not per-channel tokens. n_steps = (n_times - filter_time_length - pool_time_length + 1) // pool_time_stride + 1.

mask is an optional boolean (batch, n_chans, n_times) tensor: True replaces the raw sample with zero before the temporal convolution. Hidden samples may contain NaN; their input gradients are zero. Mask sampling and the SSL loss are downstream, with no reconstruction head. Tokens are not forced to zero: each reads all montage channels and filter_time_length + pool_time_length - 1 input samples (75 with defaults), starting at j * pool_time_stride for token j. Receptive fields overlap and are noncausal; BatchNorm during training also shares statistics across time, channels and recordings. Account for this when choosing masked spans and reconstruction targets.

There is no ch_mask: the spatial convolution has one weight per channel of the n_chans montage, so a recording cannot run on fewer channels.
